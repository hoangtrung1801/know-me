# Product

## Platform

web

## Users

The redesign prioritizes everyday personal workspace use, as confirmed by the user. Developer and AI workflows remain existing capabilities.

## Product Purpose

Know-Me brings tasks, documents, quick memos, saved links, project knowledge, memories, and decisions into a local-first personal workspace for collection and recall.

## Operating Context

The existing React web app shares storage and domain services with the Go CLI and agent integrations. People capture information, organize project work, read documents, and search their stored knowledge.

## Capabilities and Constraints

Preserve existing content and working routes, including task lists and Kanban, documents, links, memos, projects, search, graphs, chat, and settings. Maintain light and dark themes, responsive layouts, keyboard access, and native control semantics.

## Brand Commitments

Preserve the Know-Me product name and existing logo assets. The user requested replacement of the app's design system; the incumbent appearance is not a binding visual direction.

## Evidence on Hand

README.md describes the product and storage model. ui/src contains the working React implementation and assets. No commercial or usage claims are needed for this redesign.

## Product Principles

- Make everyday capture and recall easy to understand.
- Keep content legible and navigable across collections.
- Preserve the local-first workflows and existing capabilities.
- Use shared components consistently across the workspace.
