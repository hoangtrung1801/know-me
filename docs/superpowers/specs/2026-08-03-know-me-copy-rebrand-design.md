# Know-Me Copy Rebrand Design

## Goal

Present the product as **Know-Me** wherever its name appears as visible copy.

## Scope

- Update headings, prose, UI labels, descriptions, alt text, installer messages, and community templates.
- Keep technical identifiers unchanged: `knowns` commands, packages, domains, repository paths, environment variables, `.knowns` directories, binaries, and Go symbols.

## Outcome

Users see **Know-Me** in product-facing text without breaking existing installs, commands, links, or stored project data.

## Validation

Search the changed surfaces to confirm remaining `Knowns`/`knowns` occurrences are technical identifiers, then run the relevant checks for edited code or UI files.
