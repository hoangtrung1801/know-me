# Friendly README Design

## Goal

Make the English and Vietnamese READMEs welcoming, visually scannable product pages that help everyone understand, install, and start using Know-Me.

## Audience and Tone

- Audience: anyone organizing projects, tasks, useful links, and quick notes.
- Primary actions: understand the product, install it, and follow a first-use workflow.
- Tone: friendly, clear, and practical.

## Layout

1. A compact hero with a friendly product promise and navigation links.
2. A short callout explaining the everyday problem Know-Me solves.
3. A four-part visual capability grid for projects, tasks, saved links, and memos.
4. A small first-session walkthrough using existing CLI commands.
5. Retained installation, documentation, development, and community references.

## Constraints

- Modify only `README.md` and `README.vi.md`.
- Preserve existing supported commands and valid links.
- Use Markdown and existing repository images only; add no dependencies or generated assets.
- Keep the two language versions structurally equivalent and avoid unsupported claims.

## Validation

- Check that both READMEs use the same high-level sections.
- Check Markdown whitespace with `git diff --check`.
- Search for obsolete AI-coding-first positioning.
