# Security Policy

## Supported Versions

We provide security updates for the following versions of Know-Me:

| Version | Supported          |
| ------- | ------------------ |
| 1.6.x   | :white_check_mark: |
| < 1.6.0 | :x:                |

We strongly recommend always running the latest release.

## Reporting a Vulnerability

We take the security of Know-Me and its users seriously. If you discover a vulnerability, please report it responsibly.

### How to Report

1. **GitHub Security Advisory (Preferred)**:
   Submit a private vulnerability report via [GitHub Security Advisories](https://github.com/hoangtrung1801/know-me/security/advisories/new).

2. **Email (Alternative)**:
   If you cannot use GitHub Security Advisories, email the maintainers directly at **security@knowns.dev** or **howznguyen@knowns.dev**.

### What to Include

Please include as much detail as possible to help us reproduce and address the issue:
- Type of vulnerability (e.g., path traversal, command injection, authorization bypass)
- Step-by-step instructions to reproduce the issue
- Proof-of-concept script or payload (if available)
- Affected versions and operating systems
- Any proposed remediation or mitigation

### Response Timeline

- **Acknowledgment**: Within 48 hours of report submission.
- **Assessment**: Within 7 business days to confirm the vulnerability and determine severity.
- **Resolution**: We aim to release a patch within 30 days of confirmation for critical issues, adhering to standard 90-day responsible disclosure windows.

Please do not open public GitHub issues or discuss potential security vulnerabilities publicly before a fix and advisory have been published.
